## 📌 Overview  
This notebook presents a comprehensive analysis of **Washington State's electric vehicle (EV) adoption patterns**. Using advanced geospatial clustering, ensemble machine learning, and time-series forecasting, we identify key adoption drivers, predict future registration trends, and build a **CAFV (Clean Alternative Fuel Vehicle) eligibility classifier** with **94%+ accuracy**.  

The analysis is based on the **Electric Vehicle Population Data** containing **271,113 records**, and leverages tools like **GeoPandas, Folium, Seaborn, XGBoost, and LightGBM** for visualization, modeling, and forecasting.  

---

## 📂 Notebook Structure  

### 1. **🗺️ Geospatial Intelligence**  
- Interactive heatmaps & density visualizations  
- POINT geometry parsing for latitude/longitude extraction  
- Spatial clustering and regional adoption hotspot identification  

### 2. **📊 Categorical Exploratory Data Analysis (EDA)**  
- Statistical relationships & feature distributions  
- Temporal feature engineering (registration dates, model years)  
- Missing value imputation using domain knowledge  

### 3. **🤖 Ensemble Machine Learning Pipeline**  
- **EV range prediction** using stacked regressors (XGBoost, LightGBM, Random Forest)  
- **CAFV eligibility classification** with high accuracy  
- Hyperparameter tuning via RandomizedSearchCV  

### 4. **🔮 Forecasting Engine**  
- Time-series projections for **2025–2027 EV adoption**  
- Trend analysis and policy impact simulation  

### 5. **📈 Automated Reporting**  
- Publication-ready visualizations and insights  
- Actionable recommendations for policymakers and stakeholders
